# Internationalization

## Source of truth

- English strings: `m3utolocal/i18n/catalog.py` (`MESSAGES`)
- Language list: `m3utolocal/i18n/languages.py` (English first, native names)
- Catalogs: `m3utolocal/i18n/locales/<code>/LC_MESSAGES/m3utolocal.{po,mo}`

## Rebuild catalogs

```bash
python3 scripts/build_locales.py
# then fill/complete translations and recompile as needed
```

## Runtime

```python
from m3utolocal.i18n import set_language, _

set_language("es")
print(_("Confirm"))  # → Confirmar
```

## Selection

| Surface | How |
|---------|-----|
| CLI | `--lang es` / `-L es` |
| Config | `"language": "es"` in XDG config |
| Env | `LANG` / `LC_MESSAGES` |
| TUI | Settings → Language, or `L` |

Precedence: CLI > config > env > English.

## Adding a language

1. Add code + native name to `languages.py`
2. Add translations (PO) under `locales/<code>/LC_MESSAGES/`
3. `msgfmt -o m3utolocal.mo m3utolocal.po`
4. Regenerate `ports/net/m3utolocal/pkg-plist` to include new `.po`/`.mo`
